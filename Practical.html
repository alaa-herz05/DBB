SQL in 5 minutes

The mental model for every query in Parts 5–7.الفكرة الأساسية لكل الكويريات.

SELECT … FROM

SELECT col1, col2 FROM table; picks columns. * means all columns.

SELECT بتختار الأعمدة، و FROM بتحدد الجدول، والنجمة * يعني كل الأعمدة.

WHERE

Filters rows: WHERE sal > 2450. Text goes in single quotes: 'Clerk'.

WHERE بتفلتر الصفوف. النص بين علامتين تنصيص مفردة.

AND / OR / IN

AND = both true, OR = at least one. IN (10,30) is a short form of = 10 OR = 30.

AND لازم الشرطين، OR يكفي واحد، IN اختصار لعدة OR.

BETWEEN / LIKE

BETWEEN a AND b includes both ends. LIKE 'Ali%' starts with Ali; '% Ali' ends with Ali; % = any characters.

BETWEEN بتشمل الطرفين. % يعني أي عدد أحرف.

NULL

NULL means “unknown”. Never write = NULL; use IS NULL / IS NOT NULL. Any math with NULL gives NULL (sal + comm).

NULL يعني مجهول. استخدم IS NULL مش = NULL. وأي عملية حسابية مع NULL نتيجتها NULL.

Alias (AS)

sal * 12 AS annual_salary gives a computed column a readable name.

AS بتعطي اسم للعمود المحسوب.

المختبر بيستخدم Oracle وهالموقع بيستخدم محرك مشابه. SQL الأساسي نفسه.
